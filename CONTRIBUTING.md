# Contributing to JAVA_OOPS_NOTES

First off, thank you for considering contributing! Your help is appreciated in making this a great resource for others.

## How to Contribute

1.  **Fork the repository** on GitHub.
2.  **Create a new branch** for your changes: `git checkout -b feature/add-new-pattern`.
3.  **Add your code.** If you are adding a new design pattern, please place it in a new, self-contained `.java` file.
4.  **Ensure your code is well-commented**, explaining the pattern and the implementation, similar to the existing examples.
5.  **Update the `README.md`** to include a reference to your new example.
6.  **Commit your changes** with a clear and descriptive commit message.
7.  **Push your branch** to your forked repository.
8.  **Open a Pull Request** to the main repository.

## Code Style

*   Please follow standard Java coding conventions.
*   Use clear and descriptive names for classes, methods, and variables.
*   Keep the examples focused and easy to understand. The goal is education, not complex application logic.

Thank you for your contribution!
