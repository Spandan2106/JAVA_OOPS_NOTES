# Java Swing & AWT Code Examples

This folder contains sample Java programs demonstrating Graphical User Interface (GUI) development using **Java Swing** and **AWT (Abstract Window Toolkit)** as part of Object-Oriented Programming (OOP) concepts.

## 📁 Included Files

| File Name | Description |
| :--- | :--- |
| `Awt1.java` | Practical implementation of basic AWT components and event handling. |
| `Main1.java` | Introduction to Swing frame creation and basic UI elements. |
| `Main2.java` | Intermediate Swing concepts, event listeners, and layout management. |
| `SwingApp.java` | A complete Java Swing application structure demonstrating GUI execution. |

> **Note:** Compiled `.class` files (`Awt1.class`, `Main1.class`, `Main2.class`, `SwingApp.class`) are generated post-compilation.

---

## 🚀 How to Run

### 1. Prerequisites
- Install **Java Development Kit (JDK 8 or higher)**.
- Ensure `javac` and `java` commands are configured in your system environment path.

### 2. Compilation
Open your terminal or command prompt in this directory and compile any Java file:

```bash
javac SwingApp.java
